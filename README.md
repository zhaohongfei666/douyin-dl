# Douyin Downloader 🎬

Download Douyin / TikTok videos **without watermark**.

## Quick Start

```bash
python douyin_dl.py "https://www.douyin.com/video/xxxxx"
```

Video will be saved to `downloads/` folder.

## Requirements

- Python 3.6+
- `pip install requests`
