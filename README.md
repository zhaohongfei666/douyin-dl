# Douyin Downloader 🎬

Download Douyin/TikTok videos without watermark.

## Usage

```
douyin_dl.exe "https://www.douyin.com/video/xxxxx"
```

Video will be saved to `downloads/` folder.

## Requirements

- Windows
- Internet connection
- A Douyin video share link
